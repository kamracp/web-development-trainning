# web-development-trainning

Technical single-page web app for industrial energy analysis with three focused modules.

## Modules
1. **Sizing Module** – equipment capacity, motor rating, daily energy, and daily cost.
2. **Air Loss Audit** – compressed-air leak flow, leak power, annual leak energy, and annual leak cost.
3. **Energy Saving Module** – annual kWh saved, annual cost saving, CO₂ reduction, and simple payback.

## Run
Open `index.html` in a browser.
